# Project Title: Beginner Git Commands
## This project is aimed to display what beginner git commands do and how to use them correctly.
## Git Best Practices
* **Commit often:** Keep commits small, focused, and easy t review.
* **Write clear commit messages:** Use concise, descriptive messages in the imperative mood (e.g., "Add login button" insted of "Added stuff").
* **Use feature branches:** Never work directly on 'main'; create separate branches for new features or bug fixes.
* **Pull before you push:** Always fetch and pull the latest changes from the remote repository to avoid merge conficts.
* **Ignore unecessary files:** Use a '.gitignore' file to keep temporary files, dependencies, and sensitive keys out of your repository.
